# Ettanouir - Société de distribution de fournitures scolaires et bureautiques en gros

Instructions pour lancer le projet:

1. Installer les dépendances

```bash
npm install
```

2. Lancer le serveur de développement

```bash
npm run dev
```

L'application sera disponible via l'URL indiquée par Vite (généralement http://localhost:5173).

Notes:

- Le texte de l'interface est en français.
- Les données de produit se trouvent dans `src/data/products.json`.
